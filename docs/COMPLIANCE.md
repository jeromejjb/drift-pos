# Compliance & Security

This document describes Drift's compliance posture. **Internal only** — do not expose payment processor details to users.

## PCI DSS Compliance

**Claim:** PCI DSS Level 1 compliant

**Basis (internal):** We use a PCI Service Provider Level 1 certified payment processor. Card data is collected and processed by their infrastructure; it never touches our servers.

**User-facing:** Do not link to or name our payment processor. Claims are "PCI DSS Level 1 compliant" and "validated payment infrastructure" only.

---

## SOC 2 Type II

**Claim:** SOC 2 Type II report available on request

**Basis:** SOC 2 Type II is an independent audit of security controls over time. If Drift has completed a SOC 2 Type II audit, the report can be shared under NDA.

**Request access:** security@driftpos.com

**Important:** Only display SOC 2 Type II claims if you have a current, valid report from a licensed CPA firm. If the audit is in progress or not yet completed, remove or soften the claim (e.g., "Working toward SOC 2 Type II" or remove until complete).
